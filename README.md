## Featured projects

- **[Architecture as Code in open source](https://github.com/GiuseppeAllocca/architecture-as-code-mining)**: my bachelor's thesis. I mined 32,160 GitHub repositories and classified the diagrams that 239 of them keep as code, with an LLM and a public replication package.
- **[PoseGuard](https://github.com/GiuseppeAllocca/PoseGuard)**: an iOS app on the App Store that reads the AirPods motion sensors to track posture. Built in a team of 6.
- **[Gestione Magazzino](https://github.com/GiuseppeAllocca/Progetto_IDS_Los_Abuelos)**: a Java desktop app for warehouse management, with a layered architecture and JPA/Hibernate over MySQL.
- **[Los Abuelos Advisor](https://github.com/GiuseppeAllocca/Progetto-DB-Los-Abuelos)**: an Oracle database for a review platform, kept consistent by PL/SQL triggers and loaded with real Yelp data.
